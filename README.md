# restaurantejapones
Implementação do software de gestão do Restaurante Japonês da UFSCar para a matéria de Gestão de Projetos e Qualidade de Software do Professor Alexandre Alvaro.

# Como rodar o projeto

> Resumo: flask run

Este guia explica como configurar o ambiente de desenvolvimento local para rodar a aplicação Flask.

Crie o Ambiente Virtual (venv) com o código: python -m venv venv

Ative o Ambiente Virtual. Você precisa ativar o ambiente virtual toda vez que for trabalhar no projeto.

No Windows: .\venv\Scripts\activate

No macOS ou Linux: source venv/bin/activate

(Quando o ambiente está ativo, você verá (venv) no início da linha do seu terminal).

Finalmente, rode o servidor de desenvolvimento do Flask: flask run

O terminal mostrará um endereço. Você pode acessar o projeto no seu navegador, geralmente em: http://127.0.0.1:5000/
